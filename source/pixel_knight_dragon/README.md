# Рыцарь и Дракон — Забытый чертог

Отдельная двухмерная пиксельная игра по мотивам консольной университетской работы `knight and dragon.py`. Первоначальный файл не редактируется, не импортируется и не запускается при запуске новой игры. В нём остался исходный код студента. Графическая версия — дополнительная работа, созданная с помощью Codex.

## Передать преподавателю: запуск без установки

Рядом с этой папкой находится `Для_преподавателя.zip`. Передавайте **весь архив**.

1. На Windows 11 x64 распакуйте архив целиком.
2. Откройте `START_GAME.bat` — новая графическая игра.
3. Откройте `START_ORIGINAL.bat` — исходная консольная работа.

Python 3.13, Pygame 2.6.1, SDL и необходимые библиотеки встроены в поставку. Интернет, pip и права администратора для запуска не нужны. Не переносите один EXE отдельно от его папки `_internal`.

В корне комплекта лежит **побайтовая копия** `knight and dragon.py`. Для удобства проверки оригинальная консольная игра собрана отдельным EXE непосредственно из этого файла. В `source/` находятся открытые исходники обоих вариантов. Команды ниже нужны только для самостоятельной разработки или пересборки.

## Запуск исходников на Windows 11

Нужен Python 3.11 или новее. Из папки, содержащей `pixel_knight_dragon`:

```powershell
py -3 -m venv pixel_knight_dragon\.venv
.\pixel_knight_dragon\.venv\Scripts\python.exe -m pip install -r pixel_knight_dragon\requirements.txt
.\pixel_knight_dragon\.venv\Scripts\python.exe -m pixel_knight_dragon
```

При уже подготовленном локальном окружении достаточно последней команды. Активация окружения не обязательна. Можно запускать по полному пути к `pixel_knight_dragon/run_game.py` из любого рабочего каталога: пути ресурсов вычисляются относительно модулей.

Окно — 1280×720, внутренний игровой холст — 640×360, масштабирование графики без сглаживания, ограничение 60 FPS. Для читаемости кириллицы интерфейс использует PT Sans: текст со сглаживанием выводится отдельным слоем 1280×720. F11 переключает полноэкранный режим, окно можно менять в размере с сохранением пропорций.

## Управление

| Клавиша | Действие |
|---|---|
| A/D или стрелки | Идти влево/вправо |
| Space | Прыжок |
| J | Меч: 25 урона, перезарядка 0,56 с |
| K | Поднять щит: следующий полученный удар вдвое слабее |
| H | Одно из трёх зелий: +30 HP до максимума 100 |
| E | Предложение живому дракону рядом; у выхода — сбежать |
| Esc | Пауза; во время кат-сцены — перейти к её финальному кадру |
| M | Включить/выключить звук |
| F11 | Полноэкранный режим |
| Enter | Выбор в меню; после завершения кат-сцены — начать заново |

Кнопки меню также работают мышью. При потере фокуса во время боя игра ставится на паузу. На компьютере без аудиоустройства можно играть без звука.

## Бой и четыре судьбы

У рыцаря 100 HP, меч наносит 25. У Змейки 200 HP; когти наносят 10–25, огонь 10–45. Щит сохраняется до следующего полученного урона, после поглощения снимается; повторно поднимается новым нажатием K. Полное здоровье и пустой инвентарь не расходуют зелья.

Меч работает только вблизи и в сторону, куда смотрит рыцарь. Каждый взмах и каждая атака босса наносят урон не больше одного раза. В начале боя персонажи плавно появляются. Цветные метки на полу и подпись предупреждают об атаке: когти готовятся 0,65 с, огонь 0,9 с. Прыжок позволяет избегать низких атак. После атаки босс отдыхает 1,15–1,75 с. Иногда вместо удара он мяукает.

- **УБИЙЦА ДРАКОНА:** победить Змейку. Босс падает, рыцарь поднимает меч, монеты летят к герою; награда ровно 500 золота.
- **ПИКМИ НЕ ВЫЖИЛ:** потерять всё здоровье. Рыцарь падает, дракон празднует, пещера затемняется.
- **ЛЮБОВЬ ПОБЕДИЛА:** подойти к живому дракону на расстояние менее 123 пикселей и нажать E, стоя на земле. Он всегда соглашается. После предложения идёт отдельная свадебная церемония с гостями, ведущим, кольцами, фатой, цветами и конфетти. Проверок доверия и случайного отказа нет.
- **ТРУСЛИВЫЙ ПИКМИ:** идти налево через выход или нажать E рядом с ним. Рыцарь выбегает наружу; дракон остаётся в пещере.

Концовки фиксируются один раз. Через 8,5 секунды доступны кнопки повтора и главного меню. Счётчик открытых концовок сохраняется на время сеанса.

## Архитектура и связь с исходной работой

| Модуль | Назначение |
|---|---|
| `characters.py` | Character, Knight, Dragon: здоровье, оружие, зелья, щит, золото и движение |
| `combat.py` | Encounter: физика, окна попаданий, перезарядки, ИИ и выбор концовки |
| `animation.py` | Проигрывание PNG-атласов по времени |
| `resources.py` | Локальные ресурсы, шрифты и звук |
| `world.py` | Пещера, факелы, кристаллы, пепел, частицы, тени и вспышки |
| `ui.py` | Меню, HUD, здоровье, инвентарь, пауза, реплики и завершение |
| `cutscenes.py` | Четыре независимых сценария кат-сцен |
| `game.py` | Главный цикл, ввод, состояния и вывод изображения |
| `tools/build_assets.py` | Воспроизводимые оригинальные пиксельные риги, атласы и WAV |
| `tools/build_windows.py` | Два автономных EXE и архив для преподавателя |
| `tests/test_combat.py` | Автоматические проверки механик и целостности оригинала |

Сохранены классы и узнаваемые методы первоначальной работы: `attack`, `take_damage`, `heal`, `use_zelka`, `defend`, `propose`, `add_gold`, `fire_attack`, `roar`. Ходы заменены временем подготовки, окнами попадания и перезарядками. Оригинал не импортируется, поскольку в конце исходного файла сразу вызывается консольный `game.start()`.

## Ресурсы и ограничения прототипа

Все PNG, JSON, TTF и WAV находятся в `assets/`. У персонажей 19 атласов, по 8 кадров в каждом: **152 растровых кадра**. Анимации включают ожидание, ходьбу, атаки, щит, урон, смерть, предложение, победу и свадьбу. Изображения и звуки не загружаются из сети при запуске. Генератор нужен только для разработки; готовые ресурсы уже включены.

Фон пещеры — оригинальное изображение, созданное встроенным ImageGen; точный запрос записан в `ART_PROMPT.txt`. Персонажи, сцены свадьбы и выхода созданы программными пиксельными ригами и сохранены в PNG. Их стиль проще фоновой иллюстрации: это законченный небольшой учебный прототип с одним боссом, без большой кампании и профессиональной ручной анимации. Музыка и «МЯУ» синтезированы локально; это стилизованные звуки, без записи актёра. Происхождение ресурсов и лицензии — в `ASSET_CREDITS.md` и `licenses/`.

## Проверки

Из родительской папки проекта:

```powershell

$env:SDL_AUDIODRIVER = "dummy"
.\pixel_knight_dragon\.venv\Scripts\python.exe -m pixel_knight_dragon --smoke --capture-dir pixel_knight_dragon\screenshots
```

```powershell
Remove-Item Env:SDL_VIDEODRIVER -ErrorAction SilentlyContinue
Remove-Item Env:SDL_AUDIODRIVER -ErrorAction SilentlyContinue
```

## Пересборка автономного комплекта

Рядом с `pixel_knight_dragon` должен лежать неизменённый `knight and dragon.py`.

```powershell
.\pixel_knight_dragon\.venv\Scripts\python.exe -m pip install -r pixel_knight_dragon\requirements-build.txt
.\pixel_knight_dragon\.venv\Scripts\python.exe pixel_knight_dragon\tools\build_windows.py
```

Сборка использует PyInstaller 6.22.3, создаёт `Для_преподавателя/` и `Для_преподавателя.zip` рядом с исходником. Она проверяет хеш оригинала до и после сборки. Для повседневного запуска преподавателю эти команды не нужны.
