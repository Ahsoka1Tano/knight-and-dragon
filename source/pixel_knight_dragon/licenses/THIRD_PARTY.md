# Runtime components

Python and Pygame are unmodified. Their full locally included licenses are adjacent.
The Pygame Windows wheel also contains independently licensed shared libraries:

| Component | License / official source |
|---|---|
| SDL2, SDL2_image, SDL2_mixer, SDL2_ttf | zlib, https://github.com/libsdl-org |
| FreeType | FreeType License, https://gitlab.freedesktop.org/freetype/freetype |
| libpng | libpng license, http://www.libpng.org/pub/png/src/libpng-LICENSE.txt |
| zlib | zlib license, https://zlib.net/zlib_license.html |
| libjpeg | Independent JPEG Group license, https://ijg.org/ |
| libtiff | BSD style, https://gitlab.com/libtiff/libtiff |
| libwebp | BSD 3-clause, https://chromium.googlesource.com/webm/libwebp/ |
| libogg | BSD 3-clause, https://xiph.org/ogg/ |
| Opus / opusfile | BSD 3-clause, https://opus-codec.org/license/ |
| libmodplug | public domain, https://github.com/Konstanty/libmodplug |

The game uses its separate OFL PT Sans font. No Windows system font is copied.
The original student program has no Pygame dependency.
