# Происхождение ресурсов

- `sanctuary.png`: оригинальный фон, созданный встроенным ImageGen в этой сессии для данного проекта. Не заимствован из существующей игры. Полный запрос — `ART_PROMPT.txt`.
- `knight_*.png`, `dragon_*.png`, `wedding.png`, `escape.png`: оригинальная программная пиксельная графика. Исходные риги, палитры, детали брони, чешуя и все кадры — `tools/build_assets.py`. Можно воспроизвести локально.
- `audio/*.wav`: оригинальные PCM-синтезы и композиции, созданные `tools/build_assets.py`, без внешних семплов. Восемь звуковых эффектов и две музыкальные петли.
- `font.ttf`, `font_bold.ttf`: PT Sans, обычное и полужирное начертания с кириллицей. Свободный шрифт, SIL Open Font License 1.1; неизменённые файлы из [Google Fonts](https://github.com/google/fonts/tree/main/ofl/ptsans). Полный текст лицензии находится в `licenses/PTSans-OFL.txt`. Текст рисуется со сглаживанием отдельным слоем 1280×720.
- Pygame 2.6.1: LGPL 2.1; текст — `licenses/Pygame-LGPL.txt`, [исходники](https://github.com/pygame/pygame/releases/tag/2.6.1). Библиотека упакована отдельно от Python-кода игры и не модифицирована.
- Python 3.13: PSF License и включённые уведомления — `licenses/Python-LICENSE.txt`.
- Бинарные компоненты Pygame включают SDL2, SDL2_image, SDL2_mixer, SDL2_ttf, FreeType и библиотеки форматов изображений/аудио. Их уведомления перечислены в `licenses/THIRD_PARTY.md`.
- Загрузчик PyInstaller: GPL с исключением для собранных приложений; исходники сборщика доступны на [официальном GitHub](https://github.com/pyinstaller/pyinstaller).

Коммерческие ассеты, игровые персонажи сторонних студий, облачные сервисы во время игры и ключи API не используются. Исходный университетский файл принадлежит его автору; новая версия и этот файл хранятся раздельно.
